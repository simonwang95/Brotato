# Brotato Number Lab

土豆兄弟数值实验台第一版。

## 当前范围

- 手动输入角色面板属性。
- 手动输入单种武器的基础伤害、属性缩放、冷却、暴击、数量。
- 手动输入一个候选道具带来的属性变化。
- 对比购买前后：
  - 单次非暴击伤害
  - 单次暴击伤害
  - 单次期望伤害
  - 攻击间隔
  - 总 DPS

## 简化假设

第一版先只处理普通命中期望，不处理弹射、穿透、燃烧、爆炸范围命中、结构物、敌人护甲、击退导致的命中损失、溢出伤害、敌人密度等场景变量。

核心公式：

```text
缩放后伤害 = 武器基础伤害 + Σ(属性值 × 对应缩放比例)
全局修正后伤害 = max(1, 缩放后伤害 × (1 + 总伤害% / 100))
暴击期望 = 非暴击伤害 × (1 - 暴击率) + 暴击伤害 × 暴击率
攻击间隔 = 武器基础冷却 / max(0.1, 1 + 攻速% / 100)
DPS = 单次期望伤害 × 每次攻击命中数 × 武器数量 / 攻击间隔
```

## 使用

直接打开 `index.html`，或启动本地服务：

```bash
npm run start
```

然后访问 `http://localhost:5173`。

运行公式测试：

```bash
npm test
```
